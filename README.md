# LO4 - Halodoc Symptom Assistant

Lo-fi prototype of an AI-assisted symptom checker concept inspired by HILDA.

## Purpose
The prototype explores how AI can help users:
- Describe and clarify health symptoms
- Understand the urgency of their condition
- Receive a clear next-step recommendation
- Transition from AI screening to consultation with a healthcare professional

## Prototype Flow
Input Symptoms → Screening Questions → Screening Result → Doctor Recommendation

## Disclaimer
This prototype is a conceptual design and does not provide medical diagnosis or replace professional medical advice.
